# Type tiers

A type the run builds released with what carries it rather than with the
program. The load's types live in program storage for the program's life; a
type a run builds — a module's carrier at a view, a per-call nominal, a
composite over either — lives in the shortest tier that outlives what can
still reach it: a region's branch, a step's scratch branch, or a sealed body's
shape branch, each reset on its own schedule. What it buys the language: a
long-running program whose loops view modules and build types holds a bounded
lattice, and a body's types die with the body instead of with its host.
