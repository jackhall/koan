# Type tiers

A type the run builds released with what carries it rather than with the
program. The load's types live in program storage for the program's life; a
type a run builds — a module's carrier at a view, a per-call nominal, a
composite over either — lives in the shortest tier that outlives what can
still reach it: a region's branch, or a scratch branch, which a sealed body's
invariant types share and a tail loop keeps warm. What it buys the language: a
long-running program whose `Fresh` loops view modules and build types holds a
bounded lattice, a `Shares` loop one bounded by its distinct content as its
bytes already are, and a body's types die with the call instead of with its
host.
