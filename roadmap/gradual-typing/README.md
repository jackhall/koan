# Gradual typing

Generic code typed as far as its static types reach, and checked by the call
for the rest. The load fixes what the declarations decide — a call's type
parameters solved, a candidate selected, a mismatch refused — and where the
load knows only `Any`, as it does of an argument nothing ascribed or an `EVAL`
declared `-> Any`, the run carries the check. What it buys the language: a
program that states its types is refused early where they decide it, and a
program that leaves them out still runs, each call checking what the load could
not.

[The design](../../design/gradual-typing.md) follows a type from its
declaration to a call. The pieces sit in the [type lattice](../../src/type_lattice/README.md), the
[elaborator](../../src/elaborate/README.md) and
[dispatch](../../src/dispatch/README.md#static-types).

- **A knot copied whole keeps a tagged payload's hidden fields.** A copy lays
  down only what a value's type names ([crossing](../../src/values/README.md#crossing)),
  but a knot seen at its own memo is re-tied cell for cell. A tagged data node's
  memo is its identity, and its payload may be wider than the representation:
  after `LET c = (Point {x = 1, y = 2, z = c})`, a copy of `c` still lays down
  `z`. No read sees it, since the door hides it, but it counts in the copy's
  weight, and so in the copy-or-pin verdict.
